# 🎲 Random Number Generator 

A simple and modern **Random Number Generator Application** built using **React.js**.  
This project demonstrates the usage of **useState**, button click events, and **conditional rendering**.

## 📌 Features

✅ Generates random number between **1 to 100**  
✅ Updates UI instantly using **useState**  
✅ Displays message before first click: **"No number generated yet"**  
✅ Generates a new random number every time button is clicked  
✅ Modern UI with animations  
✅ Fully Responsive (Mobile / Tablet / Desktop)  

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- CSS3 (Responsive Design)

---

## 🎯 Project Objective

The objective of this project is to understand:

- How to store values using **useState**
- How to update state on button click
- How to use **conditional rendering** in React
